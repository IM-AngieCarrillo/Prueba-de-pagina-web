El proyecto

Este proyecto es un ejemplo de cómo crear una página web básica utilizando HTML, CSS y JavaScript. Van a realizar la página con estos tres lenguajes de programación, dividiendola en 2 idiomas (inglés, español) y agregando menús y un aplicativo interactivo a realizar.

¿Qué es GitHub?

GitHub es una plataforma de desarrollo colaborativo de software para alojar proyectos utilizando el sistema de control de versiones Git. Permite a los desarrolladores trabajar juntos en proyectos, realizar un seguimiento de los cambios y colaborar de manera eficiente. Git y Github son distintos: mientras git controla "los cambios" (verisiones) de forma local (por ejemplo, en tu computadora), GitHub permite compartir y colaborar en estos cambios de forma remota, es decir online como este proyecto actual.
Cuando nos referimos a "versiones", son los cambios realizados en un proyecto que se "actualizan" para que puedas verlos (en tu computador o online).
Hay términos importantes de comprender para realizar el proyecto, y son aquellos relacionados a subir versiones, agregar comentarios, entre otros.

  • Subir cambios: Tras programar debes agregar en la terminal el comando "git add ." para agregar los cambios al área de preparación.
  • Establecer cambios: Cuando ya tienes preparados tus cambios para ser subidos como una nueva versión, haces un "commit", es decir, una "confirmación". Como dice la palabra en inglés, te comprometes (commit) a ese cambio escribiendo el comando "git commit -m Cambie XYZ". Siempre tras el -m pones un espacio y dices que cambiaste.
  • Subir cambios a GitHub: Tras hacer el commit, debes subir los cambios a GitHub con el comando "git push origin main", que és como si tras confirmar lo que realizaste "enviaras el paquete".
  • Ver cambos: Si deseas ver los cambios que realizaste, puedes utilizar el comando "git log" para ver todo el listado de cambios.

En este caso, utilizaremos en todo momento la nube, realizando nuestra página en el espacio de código de GitHub (Codespace) y subiendo todos los cambios a GitHub para que se vea como página mediante la herramienta GitHub Pages.

Los objetivos

El objetivo de este proyecto es que los estudiantes aprendan a crear una página web básica utilizando HTML, CSS y JavaScript, comprendiendo la estructura de un proyecto web y cómo se interrelacionan estos lenguajes. Además, se busca que los estudiantes se familiaricen con el uso de GitHub para el control de versiones y la colaboración en proyectos.
La página constará de:

  • Un menú de navegación con enlaces a las secciones de la página.
  • Contenido en dos idiomas (inglés y español) que se pueda alternar mediante un botón.
  • Un aplicativo interactivo que permita a los usuarios realizar alguna acción o ver algún resultado en la página (bajo tutoría puede ser una calculadora, temporizador o una app meteoreológica.).
